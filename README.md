# YoutubeMusicApp
A simple Windows application for playing YouTube Music. Built using WinForms and WebView2.

## Overview
This is a simple Windows Forms application for playing YouTube Music. Built using C# and WinForms, it integrates the WebView2 component for rendering YouTube Music.

## Features
1. Play YouTube Music directly from the app
2. Custom application icon and title
3. Lightweight and standalone executable
4. Auto-updatable using PowerShell

## Installation
1. Download the latest .exe file from the Releases section.
2. Double-click the .exe to launch the application.

## Development
- .NET SDK (latest version)
- Visual Studio 2022
- WebView2 Runtime
